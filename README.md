# Utility Ownership and Residential Electricity Disconnections in 2024

## Overview

This repository contains an exploratory data analysis (EDA) of **2024 residential electricity disconnection rates among U.S. investor-owned utilities (IOUs), municipal utilities, and electric cooperatives**. It examines whether utility ownership type is descriptively associated with disconnection rates and explores differences in rate distributions, utility size, and geographic patterns.

The analysis uses a workbook associated with the Energy & Policy Institute (EPI) report, [*New nationwide data reveals utility specific disconnection information*](https://energyandpolicy.org/new-nationwide-data-reveals-utility-specific-disconnection-information/), based on U.S. Energy Information Administration (EIA) utility disconnection data.

**Research question:** How do 2024 residential electricity disconnection rates vary across investor-owned, municipal, and cooperative utilities?

## Analytical approach

The analysis combines the investor-owned, municipal, and cooperative electric-utility subsets into a consistent utility-level dataframe. It standardizes column names and disconnection-rate scales, checks for missing or questionable values, and validates reported rates against disconnection counts and customer counts.

The primary outcome is the **disconnection event rate**, calculated as annual disconnections divided by customer count. Because customers can experience more than one disconnection, this rate should **not** be interpreted as the percentage of unique customers disconnected. Comparisons include utility-level means and medians, interquartile ranges, distributions and potential outliers, utility size, within-state medians, and aggregate rates calculated as total disconnections divided by total customers.

The analysis is **exploratory and descriptive**. Differences between ownership groups do not establish that ownership causes differences in disconnection practices.

## Reproducing the analysis

1. Clone or download this repository and open it in a Python/Jupyter environment.
2. Install the notebook's dependencies from the repository root:

   ```bash
   python -m pip install -r scripts/requirements.txt
   ```

3. Open the notebook in `scripts/` and run its cells in order.
4. Ensure that the notebook's input and output paths match the directory structure above. The notebook reads the source workbook, prepares the analysis dataframe, and generates the figures and summary statistics.

The included `cleaned_df.csv` and figure files allow the resulting outputs to be inspected without rerunning the full workflow.

## Scope and limitations

This repository examines one reporting year (2024). The analysis does not establish causal effects, adjust for all differences in customer characteristics or state policy, or infer statistical significance from descriptive comparisons. Results should be interpreted in the context of the original source documentation and its data-quality limitations.
